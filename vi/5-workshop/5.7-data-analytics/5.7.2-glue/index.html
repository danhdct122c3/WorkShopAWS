Cấu hình AWS Glue

5.7.2. Khởi tạo Data Catalog với AWS Glue

AWS Glue là dịch vụ Data Integration serverless. Chúng ta sẽ sử dụng tính năng Glue Crawler của nó để tự động đọc các file log điểm danh trong S3 bucket và suy luận ra cấu trúc bảng (Table Schema) lưu vào Data Catalog.

Bước 1: Khởi tạo Database trong AWS Glue

  1. Từ thanh tìm kiếm của AWS Console, gõ Glue và chọn dịch vụ AWS Glue.

  1. Ở menu bên trái, chọn Databases dưới mục Data Catalog và bấm Add database.

  1. Đặt tên database là smart_campus_db và bấm Create database.

Bước 2: Tạo IAM Role cho Glue Crawler

  1. Từ thanh tìm kiếm của AWS Console, gõ IAM và chọn dịch vụ IAM.

  1. Truy cập vào Roles ở menu bên trái và bấm Create role.

  1. Chọn Trusted entity type là AWS service và Use case là Glue. Bấm Next.

  1. Tại bước Add permissions, tìm kiếm và tick chọn policy AmazonS3ReadOnlyAccess để cấp quyền đọc Data Lake trên S3.

  1. Tiếp tục tìm kiếm và tick chọn policy AWSGlueServiceRole. Sau đó bấm Next.

  1. Tại bước đặt tên, nhập Role name là AWSGlueServiceRole-SmartCampus.

  1. Cuộn xuống kiểm tra lại danh sách các policy đã chọn và bấm Create role.

  1. Đảm bảo Role đã được tạo thành công với thông báo hiển thị màu xanh.

Bước 3: Tạo và Cấu hình Glue Crawler

  1. Quay lại trang AWS Glue, ở menu bên trái chọn Crawlers dưới mục Data Catalog và bấm Create crawler.

  1. Tại phần Set crawler properties, đặt tên cho crawler (ví dụ: smart-campus-attendance-crawler) và bấm Next.

  1. Ở bước Choose data sources and classifiers, bấm Add a data source.

  1. Chọn Data source là S3 và dán đường dẫn thư mục S3 chứa dữ liệu Data Lake của bạn vào ô S3 path. Bấm Add an S3 data source.

  1. Kiểm tra lại thông tin cấu hình data source vừa thêm.

  1. Bấm Next để tiếp tục.

  1. Tại bước Configure security settings, chọn Existing IAM role mà bạn vừa tạo là AWSGlueServiceRole-SmartCampus và bấm Next.

  1. Ở bước Set output and scheduling, chọn Target database là smart_campus_db và Crawler schedule chọn On demand. Bấm Next.

  1. Xem lại toàn bộ thông tin cấu hình ở bước cuối cùng và bấm Create crawler.

Bước 4: Chạy Crawler

  1. Sau khi crawler được tạo xong, bấm nút Run crawler để tiến hành cào dữ liệu.

  1. Chờ khoảng vài chục giây (tuỳ lượng file log). Nếu trạng thái của crawler chuyển sang Completed, điều đó có nghĩa là quá trình tự động nội suy cấu trúc (Schema) từ các file log trên S3 đã thành công và một Table mới tương ứng đã được tạo trong Catalog!
