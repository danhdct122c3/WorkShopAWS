Cấu hình Amazon EventBridge

5.6.4. Cấu hình Amazon EventBridge (Điều phối sự kiện)

EventBridge là “trái tim” của kiến trúc hướng sự kiện. Mỗi khi Lambda xử lý xong luồng nhận diện khuôn mặt, thay vì tự nó đi gọi API gửi email, nó sẽ “phát loa” một sự kiện lên EventBridge. EventBridge sẽ nghe sự kiện này và tự động chuyển hướng nó tới các đích đến (Targets) phù hợp như SNS (để gửi Email) hoặc SQS (để lưu Log).

Bước 1: Tạo Rule (Quy tắc định tuyến) sang SNS Chúng ta sẽ tạo một quy tắc: Hễ có sự kiện điểm danh, lập tức đẩy sang SNS.

  1. Tìm kiếm dịch vụ Amazon EventBridge trên AWS Console.

  1. Ở menu bên trái, chọn Rules.

  1. Bấm Create rule.

  1. Name: Nhập attendance-recorded-to-sns. Event bus: Chọn default (hoặc Event Bus bạn đang dùng).

  1. Rule type: Chọn Rule with an event pattern. Bấm Next.

  1. Ở phần Event pattern:
    • Chọn Custom pattern (JSON editor).
    • Nhập đoạn JSON sau để bắt chính xác sự kiện điểm danh:
{
  "source": ["smart-campus.api"],
  "detail-type": ["AttendanceRecorded"]
}

  1. Bấm Next. Ở phần Select target(s):
    • Target types: Chọn AWS service.
    • Select a target: Chọn SNS topic.

  1. Topic: Chọn smart-campus-notifications (Topic đã tạo ở phần SNS).

  1. Bấm Next qua bước Add tags.

  1. Xem lại toàn bộ cấu hình ở màn hình Review và bấm Create rule.

Bước 2: Tạo Rule định tuyến sang SQS (Tuỳ chọn) Tương tự, ta sẽ tạo thêm Rule thứ 2 để đẩy sự kiện sang SQS nhằm phục vụ Data Analytics.

  1. Tại màn hình Rules, bấm Create rule lần nữa.

  1. Name: Nhập attendance-to-sqs.

  1. Chọn Rule with an event pattern rồi bấm Next.

  1. Tương tự, ở Event pattern, chọn Custom pattern (JSON editor).

  1. Nhập JSON giống hệt Bước 1.

  1. Bấm Next.

  1. Ở phần Target, chọn AWS service, nhưng lần này Select a target bạn chọn SQS queue.

  1. Chọn Queue smart-campus-analytics-queue mà bạn đã tạo.

  1. Bấm Next cho đến màn hình Review và bấm Create rule.

Đến đây, toàn bộ luồng kiến trúc hướng sự kiện (Event-Driven) đã hoàn tất!

  • Lambda phát sự kiện lên EventBridge.
  • EventBridge đẩy sự kiện ra 2 ngả độc lập: SNS (gửi Email) và SQS (lưu hàng đợi).
