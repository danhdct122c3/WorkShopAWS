# Project Worklog

## Internship Program Overview

The internship program at **FCAJ (First Cloud AI Journey)** lasted for **8 weeks**, from **June 22, 2026** to **August 15, 2026**. During this time, our team (consisting of 4 members) collaborated to build the **Smart Campus Platform** — a comprehensive **task management and attendance** system for enterprises, using a **Serverless & Event-Driven** architecture on AWS.

## Architecture & Work Breakdown

The project integrates over **10 AWS services**. To optimize the development process, the team divided the workload into 4 main areas corresponding to the 4 members:

| Role | Core Responsibilities |
|------|-----------------------|
| **Trần Minh Trí** (Frontend) | ReactJS UI, API Integration, UX |
| **Võ Thành Danh** (Backend) |  Core API (FastAPI), Database, User Auth |
| **Nguyễn Huy Hoàng** (AI & Data Analytics) | Facial Recognition, Big Data Analytics |
| **Trần Văn Khánh** (DevOps) | Event-Driven flows, Notifications, CI/CD, Monitoring |
